ISHA SURPRISE WEBSITE — GITHUB UPLOAD

1. Extract this ZIP file.
2. Open the isha_surprise_site folder.
3. Upload BOTH index.html and love-story.mp3 to the same location in your GitHub repository.
4. If using GitHub Pages, enable it in Settings > Pages and select your branch/root folder.
5. Open the published GitHub Pages URL and share it with Isha.

The song starts when she taps "Open your little surprise". The floating music button
can also play or pause it. Browsers generally block sound autoplay until someone taps.
Keep the MP3 and index.html together; the page expects the audio file to be named
love-story.mp3.
